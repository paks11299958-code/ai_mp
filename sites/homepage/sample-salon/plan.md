## 1. 비즈니스 분석

| 항목 | 내용 |
|---|---|
| 업종 | 소규모 개인 운영 프리미엄 미용실 |
| 핵심 차별점 | 10년 경력 원장의 1:1 직접 시술 + 예약제(대기 없음) |
| 전환 목표 | 카카오/전화 문의 유도 → 예약 확정 |
| 1차 타깃 | 30~50대 여성, 얼굴형에 맞는 헤어스타일을 고민하는 고객 |
| 2차 타깃 | 남성 커트·관리 고객, 품질을 중시하는 재방문 고객 |
| 가격 포지셔닝 | 합리적(여성 컷 25,000원)이나 1:1 프리미엄 경험으로 고급감 연출 가능 |
| 가장 강한 신뢰 레버 | "상담부터 시술까지 원장이 직접" — 대형 살롱과 명확히 차별화 |

## 2. 업계 분석 요약 (이 가게에 적용)

- 미용실 탐색의 **70% 이상이 모바일**. 첫 화면 로딩 3초 이내 핵심 메시지 전달 필수.
- 고객이 가장 먼저 확인하는 것: ①가격 ②실력(갤러리/후기) ③예약 편의성.
- "원장 직접 시술"은 1인 살롱의 최강 무기. 이를 전면에 노출해야 함.
- 예약제 운영은 프리미엄 포지셔닝의 근거. "기다림 없음"이 아닌 "오직 당신만을 위한 시간"으로 재해석.
- 얼굴형 분석 + 맞춤 제안은 대형 프랜차이즈가 흉내낼 수 없는 무기 → 섹션 하나를 통째로 할당.

## 3. 정보 구조 — 선택 섹션 (원페이지 앵커 내비게이션)

동네 살롱에 불필요한 섹션(Partners, Statistics, 블로그 등)은 제외. 예약 전환 흐름에 최적화된 7섹션 구성.

```
[네비게이션] 로고 · 서비스 · 소개 · 후기 · 오시는 길 · [예약하기 CTA 버튼]

① HERO          — 첫인상, 핵심 메시지, 즉각 CTA
② WHY US        — 왜 살롱 무드인가 (3개 핵심 가치)
③ SERVICE       — 메뉴 & 가격표
④ HOW IT WORKS  — 예약 → 상담 → 시술 3단계 흐름
⑤ REVIEWS       — 고객 후기 (예시 포함)
⑥ INFO          — 영업시간 · 오시는 길 · 연락처
⑦ FOOTER        — 저작권 · SNS 링크
```

> **제외 근거**: 디자이너 소개 섹션은 원장 1인이므로 WHY US에 통합. 갤러리 섹션은 실사 사진 확보 전까지 제외(스톡 이미지는 신뢰도 저하).

## 5. 디자인 시스템

### 무드 키워드
> **Dark Modern Elegance** — 절제된 럭셔리, 미니멀 컨트라스트, 골드 포인트, 넉넉한 여백, 선명한 타이포그래피

### CSS 변수

```css
--primary:    #1A1A1A;   /* 딥 차콜 — 브랜드 주조색, 헤드라인·네비 배경 */
--secondary:  #2C2C2C;   /* 소프트 블랙 — 카드 배경, 섹션 구분 */
--accent:     #C9A96E;   /* 웜 골드 — CTA 버튼, 강조 텍스트, 밑줄 */
--bg:         #F8F6F2;   /* 크림 화이트 — 기본 페이지 배경 */
--surface:    #FFFFFF;   /* 순백 — 카드, 팝업 배경 */
--text:       #1A1A1A;   /* 메인 본문 텍스트 */
--muted:      #888888;   /* 서브 텍스트, 캡션 */
--border:     #E8E4DF;   /* 카드 테두리, 구분선 */
```

### 타이포그래피

| 역할 | 서체 | 크기 / 무게 |
|---|---|---|
| 히어로 헤드라인 | Noto Serif KR (명조) | clamp(2.4rem, 6vw, 4rem) / 700 |
| 섹션 제목 | Noto Sans KR | 1.75rem / 600 |
| 본문 | Noto Sans KR | 1rem / 400 · line-height 1.8 |
| 캡션/가격 | Noto Sans KR | 0.875rem / 300 |
| 영문 강조 (살롱명) | Playfair Display | 이탤릭, 골드색 사용 |

> **근거**: 히어로에 명조(세리프)를 쓰면 "10년 경력, 장인 감성"이 텍스트만으로도 전달됨. 본문은 고딕으로 가독성 확보.

### 시각 톤 규칙

- 모서리: `border-radius: 8px` (카드), `2px` (버튼) — 날카롭되 차갑지 않게
- 그림자: `box-shadow: 0 4px 24px rgba(0,0,0,0.08)` — 소프트하고 깊이감 있게
- 여백: 섹션 상하 `padding: 100px 0` — 숨 쉬는 공간 확보
- 이미지: 다크 오버레이 (`rgba(0,0,0,0.35)`) + 텍스트 혼합 금지

## 7. 자기 비평 & 개선 반영

### 초안 비판

| 비판 포인트 | 문제 | 개선 방향 |
|---|---|---|
| **신뢰성** | 전화번호·주소 없음 → 정보 공백이 불신으로 이어질 수 있음 | INFO 섹션에 "[가게 확인 필요]" 명시 후 실데이터 입력 시 즉시 채울 것 |
| **전환** | 카카오 채널 링크가 없으면 CTA 버튼이 데드링크 | 카카오채널 or 카카오톡 오픈채팅 URL 반드시 확보 후 연결 |
| **차별성** | "10년 경력"은 경쟁자도 주장 가능 | 구체적 이력("여의도 특급 호텔 살롱 출신" 등)이 있다면 추가 시 신뢰도 대폭 상승 |
| **갤러리 부재** | 시술 전후 사진 없이 텍스트만으로는 설득력 한계 | 실제 시술 사진 최소 4~6장 확보 후 갤러리 섹션 추가 강력 권장 |
| **모바일 CTA** | 스크롤 중 예약 버튼이 사라지면 이탈 위험 | 고정 하단 플로팅 바("카카오 예약" 버튼) 추가 계획 |

### 개선 반영 완료 사항
- 서비스 섹션에 "펌·염색 가격 변동 안내" 추가 → 가격 기대치 불일치 클레임 방지
- HOW IT WORKS 섹션 추가 → 처음 방문자의 예약 불안 선제 해소
- 히어로 CTA를 2개(예약 + 서비스 보기) 배치 → 즉시 결정 못 하는 고객도 사이트 내 체류 유도
