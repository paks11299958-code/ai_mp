# DB-zone 홈페이지 기획서 (A단계)

---

## 1. 비즈니스 분석

| 항목 | 내용 |
|------|------|
| 업종 | B2B IT — Oracle DB 전문 유지보수 + AI 지능형 DB 솔루션 |
| 핵심 강점 | 20년+ 업력, 공공기관 사업 수행 경험, 24/7 모니터링, AI 예측 기술 |
| 전환 목표 | 견적/상담 문의 신청 (리드 확보) |
| 타깃 고객 | 중견·대기업 IT 담당자(DBA, IT팀장), CTO, 공공기관 정보화 담당자 |
| 구매 의사결정 키워드 | 안정성 · 전문성 · 응답 속도 · 장기 파트너십 |
| 경쟁 포지셔닝 | "전통 유지보수 + AI 혁신" 투 트랙 → 레거시 고객도, 혁신 추구 고객도 포섭 |

## 2. 업계 분석 및 전환 전략

**B2B IT 서비스 홈페이지의 방문자 행동 패턴**

- 방문자는 평균 3~5분 내에 "이 회사를 신뢰할 수 있는가?"를 결정
- 결정 요인 순서: ① 전문성 증거(업력·실적) → ② 서비스 범위 명확성 → ③ 기술 역량 → ④ 연락 용이성
- "가격이 없으면 문의 장벽이 높아진다" → 무료 상담 CTA로 진입 허들 낮추기
- 공공기관 레퍼런스는 민간 B2B 신뢰에도 강력한 신호

**핵심 전환 전략**
1. 히어로에서 즉각적인 신뢰 수치 노출 (숫자가 말한다)
2. 서비스 구분을 "지금 당장 필요한 것(유지보수)" vs "미래 투자(AI 솔루션)"로 이중 구조화
3. 모든 섹션 하단에 컨텍스트 맞춤형 CTA 배치
4. 공공기관 사업 수행 경험을 신뢰 배지로 시각화

## 7. 자기 비평 및 개선 반영

### 비판 포인트

| 비판 | 개선 방향 |
|------|-----------|
| **신뢰성**: 고객사 로고·수치가 없어 "주장만 있고 증거가 없다"는 느낌 | → 고객사명/수치 확보 즉시 추가 예정 표시, 공공기관 레퍼런스 강조로 일부 보완 |
| **전환율**: 문의 폼이 유일한 전환 경로 — 폼 기피 고객 이탈 | → 전화번호 0502-468-0502를 CTA 섹션에 전화 아이콘과 함께 병렬 노출 |
| **차별성**: "20년+, 24/7" 문구는 경쟁사도 사용 가능 | → "공공기관 사업 수행 경험"을 구체적 섹터(행정/의료/교육 등)로 세분화할 것 권장 |
| **AI 섹션 신뢰성**: AI 솔루션은 자체 개발인지 파트너 솔루션인지 불명확 | → "자체 개발" 여부 확인 후 명시 필요 — 모호하면 신뢰 저하 |
| **모바일 CTA**: 하단 고정 "전화 연결" 버튼 없으면 모바일 전환율 손실 | → 모바일 전용 fixed bottom bar: 📞 `0502-468-0502 바로 전화` 추가 권장 |

### 반영된 개선사항
- 문의 폼 옆에 전화번호를 대등하게 노출 (폼 기피 고객 탈출구)
- 서비스 카드를 2개로 명확히 분리하여 "지금 필요 vs 미래 투자" 이중 구조화
- 히어로 CTA를 Primary/Secondary 이중으로 구성 (즉시 전환 vs 정보 탐색 고객 모두 포섭)
- 과장 표현("최고", "1위") 완전 배제, 사실 기반 언어 사용
