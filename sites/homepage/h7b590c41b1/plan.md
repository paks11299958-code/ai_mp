# 충북 AI 허브센터 홈페이지 기획서

## 1. 비즈니스 분석

**업종**: AI 교육센터(학원)
**핵심 목표**: 수강 문의·상담 신청 전환 (전화/방문 상담 유도)
**타깃 고객**:
- AI를 처음 접하는 일반인·직장인 (AI 기초반)
- 자기 콘텐츠를 만들고 싶은 예비 작가·크리에이터 (AI 책쓰기반)
- 영상 콘텐츠 제작에 관심 있는 1인 크리에이터·소상공인 (AI 영상 편집반)

**강점**:
- 커리큘럼이 "개념 이해 → 실습 → 결과물 완성"까지 이어지는 실전형 구조 (책 출판, 홍보영상 제작까지 완결)
- 3단계 과정(입문 → 창작 → 영상)이 자연스럽게 이어지는 성장 로드맵 제공
- ChatGPT, Gemini, CapCut, Suno 등 실제로 널리 쓰이는 도구를 다룸 → 실용성 강조 가능

**주의**: 신청서에 수강료·강사진 정보·수상 이력·협력사·후기가 없음. 업계 표준상 이 정보들의 신뢰도 기여가 크지만, 없는 사실을 지어낼 수 없으므로 해당 섹션은 생략하거나 "[가게 확인 필요]" 처리하고, 카피는 커리큘럼·과정 구조 자체의 설득력에 집중한다.

## 4. 디자인 시스템 — "신뢰감 있는" 분위기 해석

교육기관의 신뢰감은 화려함이 아니라 **정돈된 여백, 안정적인 명도 대비, 절제된 포인트 컬러**에서 나온다. AI 학원이라는 특성상 차갑지 않게, 딥블루 계열에 따뜻한 화이트를 결합해 "전문적이지만 다가가기 쉬운" 톤으로 설정.

```css
--primary: #1E3A5F;      /* 딥 네이비 블루 — 신뢰·전문성 */
--secondary: #4A6FA5;    /* 미드톤 블루 — 보조 강조 */
--accent: #E8A33D;       /* 웜 앰버 — CTA 버튼, 소량 포인트 */
--bg: #FAFAF8;           /* 웜 오프화이트 배경 */
--surface: #FFFFFF;      /* 카드 배경 */
--text: #1A1F2B;         /* 본문 텍스트 */
--muted: #6B7280;        /* 보조 설명 텍스트 */
--border: #E5E7EB;       /* 구분선, 카드 테두리 */
```

- **타이포 스케일**: 히어로 헤드라인 대형(예: 48~64px, 굵게), 섹션 제목 28~32px, 본문 16~18px, 여백을 충분히 확보한 계층 구조
- **무드 키워드**: trustworthy minimal, soft shadows, rounded corners(8~12px), generous white space, 딱딱하지 않은 그리드 카드 레이아웃
- **버튼**: accent 컬러 배경, 둥근 모서리, 호버 시 미세한 그림자 확대

## 5. 자기 비평 및 보완

**신뢰성 측면**: 강사진 프로필, 수강료, 후기, 취업 성공 사례 등 업계 표준 신뢰 요소가 신청서에 전무하다. 이대로면 방문객이 "가격도 모르고 강사도 모르는데 전화만 하라"는 인상을 받을 수 있어 전환율이 제한될 수 있다. → 현재는 커리큘럼의 구체성(단계별 세부 항목)으로 전문성을 대신 증명하되, **후속 단계에서 반드시 수강료·강사 소개·후기 정보를 받아 추가할 것을 권장**한다.

**차별성 측면**: "AI 기초 → 책쓰기 → 영상 제작"으로 이어지는 3단계 로드맵 자체가 이 학원만의 스토리다. ④ 섹션에서 이를 "추천 대상"으로 풀어냈지만, 향후 "3단계를 순서대로 밟으면 어떤 결과물이 남는가"를 시각적 타임라인으로 강조하면 차별성이 더 명확해진다.
