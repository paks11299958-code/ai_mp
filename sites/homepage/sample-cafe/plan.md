## 2. 업계 분석 요약

국내 소규모 로스터리 카페 홈페이지의 전환 실패 패턴은 크게 두 가지다. ① 브랜드 철학 없이 메뉴표만 나열하거나, ② 대형 카페 레이아웃을 그대로 복사해 "왜 이 카페여야 하는가"를 전달하지 못한다. 볕들카페는 반대로 가야 한다 — **로스팅이라는 행위를 스토리로 만들고**, 공간의 온기를 시각적으로 선체험하게 해 "한번 가봐야겠다"는 욕구를 만들어야 한다.

성공하는 골목 카페 홈페이지의 공통점:
- 히어로에서 분위기를 즉각 전달 (텍스트보다 이미지가 먼저)
- 메뉴는 가격보다 '이야기'가 앞선다
- 오시는 길은 골목 특성상 반드시 보완 설명 포함
- 모바일에서 한 화면 안에 영업시간·CTA가 보여야 함

## 5. 디자인 시스템

### 컬러 팔레트 — "따뜻한 햇살 미니멀"

```css
:root {
  --primary:   #7B4F2E;  /* 에스프레소 브라운 — 브랜드 핵심 */
  --secondary: #C49A6C;  /* 카라멜 골드 — 포인트 텍스트 */
  --accent:    #E8C99A;  /* 밀크티 베이지 — 버튼 호버, 구분선 */
  --bg:        #FDFAF5;  /* 크림 화이트 — 전체 배경 */
  --surface:   #F5EDE0;  /* 따뜻한 베이지 — 카드, 섹션 배경 */
  --text:      #2A1A0E;  /* 다크 에스프레소 — 본문 */
  --muted:     #9B826A;  /* 라떼 브라운 — 부제, 캡션 */
  --border:    #E2D3C0;  /* 부드러운 모카 — 구분선, 테두리 */
}
```

### 타이포그래피

| 역할 | 폰트 | 크기 |
|------|------|------|
| **히어로 헤드라인** | Noto Serif KR (또는 Gowun Batang) | 56–72px, weight 700 |
| **섹션 헤드라인** | Noto Serif KR | 32–40px, weight 600 |
| **본문** | Noto Sans KR | 16–18px, weight 400, line-height 1.8 |
| **메뉴 가격** | Noto Sans KR | 14px, weight 500, color --muted |
| **CTA 버튼** | Noto Sans KR | 15px, weight 600, letter-spacing 0.05em |

### 무드 키워드
`warm minimal` · `soft morning light` · `generous white space` · `subtle warm shadows` · `rounded corners (12–20px)` · `hand-crafted texture` · `unhurried pace`

### 레이아웃 원칙
- 최대 콘텐츠 너비: 960px (좁게 잡아 집중도 유지)
- 섹션 패딩: 상하 100px
- 모바일 우선 (타깃의 70%+ 모바일 유입 예상)
- 애니메이션: fade-in-up 0.6s ease, 과한 모션 금지

## 7. 자기 비평 및 보완

### 비판 1 — 주소·전화번호 부재
신청서에 주소와 연락처가 없다. '오시는 길' 섹션이 가장 중요한 전환 포인트임에도 지도를 채울 수 없다. **보완:** `[가게 확인 필요]` 명시 후, 실제 HTML 구현 단계에서 카카오맵 임베드 코드만 교체하도록 placeholder 처리한다.

### 비판 2 — 후기(Testimonials) 부재
신청서에 후기 자료가 없다. 골목 카페의 신뢰도 구성에 후기는 강력한 무기다. **보완:** FAQ 아래 짧은 후기 블록을 [예시] 라벨로 넣고, 가게 측이 실제 후기로 교체할 수 있도록 마크업을 단순하게 유지한다.

> [예시] "아침에 갓 볶은 원두 향이 카페 문 앞에서부터 납니다. 창가 자리에서 두 시간을 보냈어요." — 방문 고객
> [예시] "스콘이 생각보다 훨씬 맛있었어요. 버터향이 살아있고 결이 예뻐요." — 방문 고객

### 비판 3 — 원두 판매 여부 미확인
직접 로스팅한다면 원두 판매는 강력한 추가 전환 포인트다. **보완:** FAQ에 원두 구매 항목을 넣고, 판매 여부 확인 후 별도 '원두 소개' 서브 섹션 추가를 권장한다.

### 비판 4 — SNS 연동 미확인
계절 디저트처럼 자주 바뀌는 정보는 홈페이지보다 인스타그램이 더 적합하다. CTA에 인스타그램 링크를 넣었으나 계정 확인이 필요하다.
