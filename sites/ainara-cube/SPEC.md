# AINARA 큐브 퍼즐 사이트 — 개발 사양

> 운영 URL: `https://aiworld.dbzone.kr/` (Vercel 프로젝트 `aiworld`)

> 목적: `sites/ainara-partner` 의 **사업 내용은 100% 그대로**, **비주얼만 완전히 새로**.
> 컨셉 = 마우스에 반응해 회전하는 3D 큐브 퍼즐 → 서비스 영역이 화면에 들어오면 큐브가
> 한 번 자연스럽게 흩어지며 각 조각이 서비스(기능) 카드로 펼쳐진다.

## 절대 지킬 것

1. **외부 CDN·라이브러리 금지.** Three.js 등 반입 금지. **Canvas 2D 로 직접 그린다.**
   (사이트 전체 규칙: `ai_mp/doc/features/sites_system.md`)
2. **canvas 는 최대 1개.**
3. **`prefers-reduced-motion: reduce` 면 애니메이션을 전부 끄고** 정적 대체 화면을 보인다
   (큐브 대신 조용한 그리드 배치 등). canvas 자체를 만들지 않아도 된다.
4. **모바일에서 가로 스크롤 0.** 360px 에서도 깨지지 않아야 한다.
5. **이미지에 `height:auto`** 를 반드시 준다. HTML 의 `width/height` 속성이 남으면
   `aspect-ratio` 가 무력화돼 이미지가 잘린다(실측 사고).
6. 모바일 분기점은 **820px** 를 쓴다(620px 는 요즘 기기에 좁다 — 실측).
7. 사업 문구·숫자를 **바꾸거나 지어내지 말 것.** 아래 내용을 그대로 옮긴다.

## 비주얼 컨셉

### 1) 히어로 — 어두운 배경 위의 큐브 퍼즐

★**히어로는 어두운 풀블리드 배경**이다(2026-08-26 사장 지시). 밝은 아이보리 배경이면
요소가 다 연하게 깔려 첫인상이 약하다. 기존 `ainara-partner` 의 **CTA 섹션 방식**을
히어로에 그대로 가져온다 — 세 겹을 겹쳐 깊이를 만든다:

```
1층  배경 이미지        assets/img/cta.png (골든아워 회의실)  object-fit:cover
2층  그라데이션 베일    linear-gradient(105deg,
                         rgba(15,15,14,.93) 0%, rgba(15,15,14,.82) 46%,
                         rgba(201,100,66,.55) 100%)
3층  큐브 canvas        opacity 0.85 안팎, pointer-events:none
4층  카피(흰 세리프 제목 + 밝은 회색 본문 + 버튼)
```

- 제목은 **흰색 세리프**(`--serif`), 본문은 `#d9d7cf`, 배경이 어두우므로 대비가 충분해야 한다.
- 버튼: `파트너 신청하기` = 테라코타 채움 / `라이선스 자세히 보기` = 반투명 흰 테두리
  (`background:transparent; color:#faf9f5; border-color:rgba(250,249,245,.34)`).

**큐브 자체**
- **3×3×3 큐브**를 Canvas 2D 로 그린다. 실제 3D 라이브러리 없이
  **등각/원근 투영을 직접 계산**한다(정점 회전 → 2D 투영).
- **마우스 위치에 따라 회전각이 따라온다.** 마우스를 안 움직이면 아주 천천히 자전.
  포인터가 없는 기기(터치)에서는 자전만 한다.
- ★어두운 배경 위에 얹히므로 **큐브 면은 밝게** 칠한다(아이보리~웜그레이 계열 + 테라코타
  포인트, 면마다 미세한 명암). 선은 밝은 실선. 밝은 배경 기준으로 칠하면 묻힌다.
- 헤더가 sticky 이므로 히어로 상단이 헤더에 가리지 않게 여백을 준다.

### 2) 서비스 영역 진입 → 큐브 자동 분해
- 히어로 다음 서비스 영역이 화면에 약 30% 들어오면 큐브 조각(27개 중 대표 9개)이
  바깥으로 흩어지는 애니메이션을 **한 번 자동 재생**한다. 흩어지는 동안 각 조각이
  **서비스 카드**로 바뀐다.
- 완전히 펼쳐지면 카드 9개가 격자로 정렬돼 **AI 임대형 9개 서비스**를 보여준다.
- 스크롤은 시작 신호일 뿐 진행률을 조종하지 않는다. 사용자가 스크롤을 멈추거나 위로
  되돌려도 애니메이션은 끝까지 진행하고, 완성된 메뉴 상태로 고정한다.
- 재생 시간은 PC 약 1.4초, 모바일 약 0.95초로 하며 `requestAnimationFrame` 하나만 쓴다.
- 모션 감소 설정에서는 자동 재생 없이 완성된 카드 메뉴를 즉시 표시한다.
