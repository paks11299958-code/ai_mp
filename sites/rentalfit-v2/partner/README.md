문안 근거는 저장소 `assets/공고-최종본.md` 3절입니다. 자주 묻는 질문은 그 절의 문장을 질문·답변으로 재배열했습니다. 다른 절의 문의 안내 문장은 같은 연락 경로의 표현이며 별도 혜택이나 조건을 추가하지 않았습니다. 등록·정산 주체는 행복컴퍼니이고 안내·상담은 ㈜디비존입니다.

## 로컬 검증과 공백

`qa/verify.py`는 임시 127.0.0.1 서버와 Chromium을 띄워 390·1280px, 글자 100·150% 네 경우를 검사하고 캡처와 `qa/verification.json`을 만듭니다. 외부 요청은 차단하며 시도 횟수도 기록합니다. 질문 4개 펼치기, 전화 링크 값, 두 자리 링크, 이미지 로딩, 가로 넘침과 첫 화면 요소 좌표를 검사합니다. 실제 전화 발신은 하지 않습니다.

실행 환경에 설치된 Playwright 사용 명령:

```sh
PYTHONPATH=/home/paks11299958/rag-env/lib/python3.11/site-packages python3 partner/qa/verify.py
```

기본 샌드박스는 소켓을 차단하여 첫 실행이 실패했습니다. 로컬 검증만 허용하는 실행 권한으로 재실행했습니다. 외부 네트워크를 통한 패키지 설치나 공개 웹 조사는 하지 않았습니다.
