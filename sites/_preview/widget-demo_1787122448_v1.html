WHY widget-demo

작은 글씨 하나에도, 기준이 필요합니다

하단 한 줄은 "이 페이지가 살아 있다"는 가장 짧은 신호입니다. 날짜에 상태를 더하면, 그 신호는 증거가 됩니다.

시간대 자동 보정

서버 시간이 아니라 방문자의 로컬 시간을 기준으로 렌더합니다. 자정 경계에서도 어긋나지 않습니다.

상태 라벨 한 마디

data-status="done" 하나면 날짜 옆에 '테스트 완료'가 붙습니다. 색·문구·크기는 토큰으로 조정합니다.

렌더 차단 없음

defer 로드에 DOM 조작 1회. 자리부터 잡고 채우기 때문에 CLS와 Lighthouse 점수에 영향이 없습니다.

VERIFIED

'테스트 완료'는 장식이 아닙니다

세 가지 검사를 모두 통과한 배포에만 라벨이 붙습니다. 하나라도 실패하면 라벨은 조용히 사라집니다.

렌더 검증실제 브라우저에서 하단 요소가 그려졌는지 확인
날짜 정합성표기 문자열과 datetime 속성이 같은 날을 가리키는지 대조
접근성 통과대비 4.5:1 이상, 스크린리더에서 캡션으로 읽힘
INSTALL

붙여넣기 한 번이면 끝

  1. </body> 바로 위에 스크립트를 붙입니다.
  2. 날짜를 넣을 위치에 #widget-demo 요소를 둡니다.
  3. data-status로 '테스트 완료' 라벨을 켭니다. 재배포는 필요 없습니다.
