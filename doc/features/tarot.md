## 카드 뽑기 흐름 단순화 (2026-07-21, 사장 지시)

기존엔 카드 1장 뽑을 때마다 개별 해석을 요청+대기(3회)한 뒤 종합 리딩(1회)까지 AI 호출 **4회**가 발생 — 사장이 실제 카드섞기 화면을 보고 "3장 한번에 뽑고 결과도 한번에" 제안, 절충안으로 확정:
- **카드 뽑기는 대기 없이 연속 진행**(부채꼴 클릭하는 재미는 유지) — `TarotCardModal.tsx`의 `pick()`이 매번 채팅 전송하지 않고 `drawn`에만 쌓음.
- **AI 호출은 3장 다 뽑은 뒤 종합 1회만** — `askSummary()`가 3장 정보를 전부 프롬프트에 담아 한 번에 전송. 개별 해석 요청(`askYuna`)은 제거.
- `mode='daily'`(오늘의 카드 1장)는 원래도 1장+즉시 해석 구조라 변경 없음.
- 채팅 메시지 전송 1건=일일 무료 한도 1회 소모(위 "과금" 참고)라, AI호출 4→1회로 사용자의 무료 대화 소모도 그만큼 감소.
