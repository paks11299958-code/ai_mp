> 다른 페르소나는 기존 진입 시트를 그대로 쓴다.

## 왜 하는가

지금 페르소나에 들어가면 **채팅창이 먼저** 보인다. 사장 지적:

→ 도결 선생을 클릭하면 **사주 사이트 같은 큰 랜딩 화면**이 먼저 뜨고,
거기서 기능을 고르거나 채팅으로 들어간다.

### 히어로 연출 (★사장 지시의 핵심)

**역술가의 오래된 책 → 연기가 피어오르며 책이 사라짐 → 한국 호랑이가 천천히 나타남**

- 이미지 2장이 이미 있다: `/saju/book.png`, `/saju/tiger.png` (public, 1216×832)
- **Canvas 2D 로 연기·안개 + 크로스페이드**를 그린다. 외부 라이브러리 금지.

★**두 이미지에 이미 실제 연기가 찍혀 있다**(책=향로 연기, 호랑이=주변에 감도는 연기).
캔버스가 그리는 연기는 **그 사진의 연기와 이어붙이는** 역할이다 — 처음부터 다 그리려 하지 말 것.
책의 향로는 화면 중앙 상단, 호랑이의 연기는 좌우에 있으니 발생 위치를 거기에 맞춘다.

**타임라인** (약 6초, 1회 재생 후 호랑이 상태로 정지)

| 구간 | 연출 |
|---|---|
| `0 ~ 1.5s` | 책만. 향로 위에서 **연기가 서서히 짙어지기 시작** |
| `1.5 ~ 3.5s` | **연기(피어오름)** — 아래에서 위로 솟구쳐 책을 감싼다. 책이 페이드아웃 |
| `3.5 ~ 5.5s` | **안개(깔림)로 전환** — 화면 전체에 옆으로 퍼지고, 그 속에서 호랑이가 서서히 드러난다 |
| `5.5s ~` | 호랑이 유지. 안개만 은은하게 남아 천천히 흐른다 |

흐름은 **"책이 연기에 삼켜지고 → 안개가 걷히며 호랑이가 나타난다"** 이다(2026-08-26 사장 확정).

**연기와 안개는 성질이 다르다 — 둘을 구분해 그릴 것**
- **연기**: 발생점(향로)에서 **위로 상승**. 입자가 작게 시작해 커지며 옅어진다.
  좌우 흔들림(sin 파동)을 주고, 상승할수록 흔들림 폭을 키운다.
- **안개**: **가로로 느리게 흐른다**. 큰 반투명 덩어리 여러 겹이 서로 다른 속도로 움직여
  깊이를 만든다. 상승은 거의 없다.
- 둘 다 `radialGradient` 로 가장자리를 흐리게 하고, `globalCompositeOperation` 은
  `'lighter'` 가 아니라 기본값 또는 `'screen'` 을 쓴다(먹색 배경에서 `lighter` 는 탄다).
- 입자 수는 PC 40~60, 모바일 20~30 정도. **화면 밖이면 rAF 정지**.

- ★`prefers-reduced-motion` 이면 **캔버스 없이 호랑이 이미지만** 정적으로 보인다.

1. **`App.tsx` 수정 금지.** 분기는 `PersonaEntrySheet` 안에서.

9. **사실 창작 금지** — 연락처·가격·실적·후기·통계를 지어내지 말 것. DB 값과 위 문구만.
