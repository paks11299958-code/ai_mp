## 1. 왜 만들었나

아린은 담당 기능이 **5개**인데 전부 기능 카드로 흩어져 있어 "가게 홍보를 맡아주는 곳"이라는
정체가 드러나지 않았다. 페르소나에 들어가면 채팅창부터 떠서 무엇을 할 수 있는지 안 보였다.

## 2. ★정체성을 먼저 물었다

시안을 그리기 전에 사장 확인을 받았다([[feedback_design_identity_first]] 적용 —
09-06 윤채린에서 "정체성을 안 묻고 그럴듯한 걸 만들어" 세 번 지적받은 전례).

기능 5개가 **한 정체성으로 안 묶인다**는 것이 조사에서 드러났다:

| 기능 | 성격 |
|---|---|
| AI 마케팅 글쓰기 · 쇼츠 만들기 · 중고 판매글 · 핫 키워드 | 가게 홍보 |
| 이미지 → 프롬프트 | **결이 다름** (AI 창작 도구) |

→ 사장 확정: 앞 4종을 메인으로, 이미지→프롬프트는 **"이건 좀 다른 재주예요"로 분리**.

컨셉은 대화 중 **3번 진화**했다(기록해 둔다 — 되돌아갈 때 근거가 된다):
1. "내 가게 홍보해주는 인플루언서" (인물 히어로)
2. **"컨셉을 인플루언서로 안 봐도 됨. 여러 업종 가게를 움직이게 하는 페이퍼 영상"**
3. **"아린이가 하나씩 불러오는 소환 느낌"** → **"폰 없애고 손으로 받치기"**

## 3. ★업계 조사가 그대로 설계도가 됐다

추측으로 만들지 않았다. 실제 관행을 찾아 그대로 옮겼다.

- **얼굴 없는 릴스가 이미 하나의 장르다** — 얼굴은 프레임 밖으로 빼고 손과 결과물만
  밝게 찍는다. **사장이 인물 컨셉을 뺀 것과 업계 흐름이 정확히 일치했다.**
- 구성은 **7~12초 4단**: `결과물 → 손동작 하나 → 결과 재노출 → 지역명+예약/문의`
  → 화면 하단 **진행 칩**으로 그대로 노출한다.
- **업종별로 찍는 소품이 정해져 있다** — SVG 소품을 이 표에 맞춰 그렸다.

| 업종 | 0-3초 | 3-8초 |
|---|---|---|
| 카페 | 완성된 라떼 한 컷 | 크림을 붓는 손 |
| 미용실 | 완성된 스타일 | 가위와 드라이 손동작 |
| 학원 | 오늘 배울 것 한 줄 | 교재와 칠판 클로즈업 |
| 음식점 | 김 나는 대표 메뉴 | 국물 붓고 고명 올리기 |
| 병원 | 진료 안내 한 화면 | 예약 시간 고르기 · **심의 확인** |

🔴**의료광고는 사전심의 대상**이다. 처음엔 그래서 병원을 뺐다가 **사장 요청으로 되살렸다** —
심의는 '광고를 실제 집행할 때' 걸리는 절차지 랜딩에 업종을 소개하는 것과 다르다.
빼서 모르게 두는 것보다 카드에 "· 심의 확인"을 적어 **알려주는 쪽이 실무에 낫다**.

## 4. 구조

- 아린이 **손으로 받쳐** 업종 카드를 하나씩 소환한다(4.6초 주기, 점으로 직접 선택 가능).
- 앞서 소환된 장은 뒤에 겹쳐 남아 "여러 업종을 이미 만들어 줬다"로 읽힌다.
- ★**아린 z-index(6) > 카드(5)** — 아래면 손이 카드에 가려 '받쳐 든' 게 아니라
  그냥 옆에 선 사람으로 보인다(렌더로 확인).
- 종이 질감은 **SVG `feTurbulence`**(파일 0KB). ★`pointer-events:none` 없으면
  이 층이 클릭을 다 먹는다.
- 애니메이션은 **`.is-on` 카드에서만** 돈다(안 보이는 카드까지 돌면 배터리를 먹는다).
  탭이 백그라운드면 정지, `prefers-reduced-motion` 이면 자동 순환을 걸지 않는다.

**인물 자산 만드는 법**(재현용): 흰 배경 i2i → 알파 임계 → **`joinChannel` 로 알파 주입**.
★`dest-in` 합성은 모서리가 불투명하게 남고, `linear` 로 실루엣을 부풀리면 화면 전체가
흰 판이 된다 — **둘 다 실패했다**. 검증은 눈이 아니라 **모서리 픽셀 알파값 0** 으로 한다.

## 5. ★★함정 (실측으로 걸린 것)

| 증상 | 원인 |
|---|---|
| 보드를 닫으면 **메인으로 떨어짐** | 아린 보드 4종에 `closeBoardAndReturn` 배선이 없었다 → main·chat **양쪽 8곳** 배선 |
| **이미지→프롬프트에서 못 돌아옴** | 보드가 아니라 **최상위 얼리리턴 라우트**(`window.location.href`)라 앱 전체가 갈아치워진다 |
| 복귀 URL 을 저장했는데 **메인으로 감** | 🔴App.tsx 가 딥링크를 소비하며 **`?p=` 를 URL 에서 지운다**(`params.delete('p')` + `replaceState`, App.tsx:226). `location.search` 는 **비어 있다** |
| 배선 누락을 테스트가 **못 잡음** | 검사가 **한 줄 단위**라 `HotKeywordBoard` 처럼 여러 줄에 걸쳐 렌더되는 보드를 놓쳤다 → `<Board …/>` **덩어리 단위**로 수정 |
| 손이 카드에 가려 '받침'이 안 보임 | z-index 가 카드보다 낮았다 |
| 사진 가장자리를 흐려도 **사각 티가 남음** | 배경이 꽉 찬 사진은 마스크로 못 지운다 → **누끼가 근본 해결** |

**페이지 이동형 기능의 복귀 규약**(이 화면에서 신설):
`sessionStorage['rp:backTo']` 에 `/?p=<personaId>` 를 남기고, `ReversePromptMain` 이
읽어 `RpHeader backTo` 에 넘긴다. ★**양쪽 키가 어긋나면 에러 없이 메인으로 떨어진다** —
회귀 테스트(`entryReturn.test.ts`)로 짝을 고정했다.
★열린 리다이렉트 방지: **같은 출처 경로만** 허용(`/`로 시작하고 `//` 아님).
