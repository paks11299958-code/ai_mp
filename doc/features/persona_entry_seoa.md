# 서아 뉴스데스크 진입 화면 — 사양서

> 2026-08-27 사장 지시. 도결 선생 사주 진입화면([[persona_entry_saju]])의 **두 번째 적용**.
> 겸하여 **허드 어드민 콘솔 2단계 검증**(어드민 폼 → 허드 실행)의 실제 과제로 쓴다.

## 1. 무엇을 만드는가

페르소나 **서아**를 클릭하면 채팅창 대신 **뉴스데스크 랜딩**이 뜬다.
서아가 데스크에 앉아 **환율·주가·날짜·절기·뉴스**를 한 화면에서 브리핑하는 느낌.

사장 원문:
> 환율 주식 날짜 절기 뉴스 등 뉴스데스크 분위기, 서아가 앉아서 다 처리해주는 느낌.
> 밝은 인사는 꼭 넣고, 아침 점심 저녁 시간에 맞춰 조명도 바뀌게, 서있는 모습과 앉아 있는 모습 두 가지를 랜덤하게.

## 2. ★도결과 다른 점 — 그대로 베끼면 안 된다

| | 도결 선생 | 서아 |
|---|---|---|
| `quickMenuJson` | 1,544자(기능 8개) | **0자 — 비어 있음** |
| `features` | 코드 폴백 | `["news"]` **1개** |
| 기능 실행 | `/quick-menu-result` 재사용 | **`NewsPage` 별도 화면** |

도결은 "채팅으로 튕겨 나가는 문제"를 풀었지만 **서아는 그 문제가 없다**(이미 전용 화면).
그래서 이 화면의 목적은 **"뉴스 하나"를 "비서 대시보드"로 넓히는 것**이다.

## 3. ★★과금 경계 (절대)

**뉴스 본문은 유료다.** `MenuLimit` 실측(2026-08-27):

| feature | role | pointsCost |
|---|---|---|
| news | USER | **50P** |
| news | ADMIN/MANAGE | 100P |

`GET /api/aimp/news/today` 는 **로그인 필수 + 조회 성공 후 차감**한다(`news.ts:72`).
`GET /api/aimp/news/tts` 는 **로그인 필수지만 캐시 파일 조회만 하며 차감하지 않는다**.

따라서:
- **랜딩에 들어온 것만으로는 절대 차감하지 않는다.** `/today` 를 자동 호출 금지.
- 뉴스 칸은 **카테고리 선택 UI까지만** 무료로 보여주고, **사용자가 카테고리를 누를 때** 기존 경로로 호출한다.
- 글로 보기 버튼에는 서버 단가를 표시하고, ▶에는 **무료 듣기**임을 명확히 안내한다.
- ★단가는 사장 관리 항목이다 — **코드에 숫자를 박지 말고** 서버가 주는 값을 쓴다.

시세·환율·날짜·절기는 **전부 무료**다(외부 조회, AI 호출 없음).

## 4. 데이터 소스 — 전부 실측 확인됨 (2026-08-27)

| 칸 | 소스 | 실측 |
|---|---|---|
| 📈 코스피 | **네이버 지수 `KOSPI`** | **6,912.37 / +104.16 (+1.53%)** ✅ |
| 📉 코스닥 | **네이버 지수 `KOSDAQ`** | **837.65 / +10.78 (+1.30%)** ✅ |
| 📈 지수(폴백) | 토스 `069500`·`261240` KODEX | 109,135원 ✅ (지수 실패 시만) |
| 💱 환율 | 네이버 금융 `FX_USDKRW` | **1,380.40원 / 0.14 상승** ✅ |
| 💱 환율(폴백) | 토스 `138230` KODEX 미국달러선물 | 16,160원 ✅ |
| 📅 날짜 | `/api/desk/summary` 서버 KST | 브라우저 시계 불사용 |
| 🌿 절기 | **코드 내장 표** | API 불필요 |
| 📰 뉴스 | 기존 `/api/news/*` 프록시 | 8개 카테고리, 본문만 서버 단가 차감 |

★**토스에 지수·환율 심볼은 없다.** `KOSPI`·`KS11`·`USDKRW` 는 빈 배열을 반환한다
(에러가 아니라 빈 값이라 **성공한 줄 알기 쉽다**).

★★**그래서 처음엔 ETF로 대체했는데, 그게 사고였다**(2026-08-27 사장 지적).
화면에 "코스피 109,135원"이 찍혀 지수로 오해됐다. **대용은 근사도 아니다** —
자릿수도 등락률도 다르다. 지수는 `polling.finance.naver.com` 이 준다:

```
GET https://polling.finance.naver.com/api/realtime/domestic/index/KOSPI,KOSDAQ
    Referer: https://finance.naver.com/     ← 없으면 거부될 수 있다
```
★이 API 는 **JSON(UTF-8)** 이다. 환율 스크래핑과 달리 euc-kr 디코딩이 필요 없다.
★전일대비가 **절댓값**으로 온다 — `compareToPreviousPrice.code`(2=상승/5=하락)로
  부호를 복원한다. 구현: `shared-api/lib/seoa/naverIndex.ts`

★**환율 ETF(`138230`)는 "달러 값"이 아니다** — 16,160원이지 1,380원이 아니다.
방향(등락률)만 유효하다. 그래서 **네이버가 1차, 토스는 폴백**이다.

★네이버 응답은 **euc-kr** 이다. UTF-8로 읽으면 깨진다.

**신규는 시세·환율 조회 라우트 1개 + 진입 화면 컴포넌트뿐이다.**

### 6-1. 뉴스 TTS 슬롯 계약 (2026-08-28 보완)

뉴스와 TTS 파일은 오전·오후 슬롯별로 생성된다. 서아 뉴스데스크의 ▶ 재생도 기존
`TodayNewsBoard`와 동일하게 **현재 생성된 슬롯을 반드시 전달**해야 한다.

```text
GET /api/news/status
→ { "available": true, "slot": "am", "slots": ["am"],
    "headline_cues": { "국내뉴스": [{ "title": "뉴스 제목", "at": 0.02 }] } }

GET /api/news/tts?category=국내뉴스&slot=am
```

- `slot`은 `am` 또는 `pm`만 허용한다.
- 화면 마운트 때 `/api/news/status`를 무료 조회하여 최신 슬롯을 저장한다.
- 상태 조회가 끝나기 전에 ▶를 누른 경우 재생 시점에 상태를 한 번 더 조회한다.
- **슬롯 없는 `/api/news/tts?category=...` 호출 금지.** agent-api 실측상 최신 슬롯 파일이
  있어도 슬롯 없는 요청은 `404`, `slot=am`을 붙인 요청은 `200`을 반환했다.
- TTS는 로그인만 필요하고 포인트 차감은 없다. `/today` 본문 조회와 과금 계약을 섞지 않는다.
- `headline_cues`는 무료 제목 자막용이다. 카테고리별 최대 12개, 제목 최대 160자와
  전체 음성 대비 대략 위치(`0..1`)만 반환하며 본문·핵심 내용·출처는 포함하지 않는다.
- 구현: `frontend/components/persona/SeoaNewsDeskEntry.tsx`
- 회귀 테스트: `frontend/components/persona/SeoaNewsDeskEntry.test.ts`

## 8. 완료 조건

1. 서아 클릭 → 뉴스데스크 랜딩(채팅창 아님)
2. 서버 KST 시간대에 맞는 인사말, 히어로 이미지는 필터 없이 원본 유지
3. 선/앉은 이미지 랜덤

6. 뉴스 카테고리 선택 → 기존 경로로 조회, **서버가 내려준 단가 표기**
7. **진입만으로는 포인트가 차감되지 않음**(실측 확인)
8. 390 / 820 / 1440 폭에서 잘림·겹침 없음
9. 뉴스 ▶ 재생 → `/api/news/status`의 최신 슬롯을 포함한 TTS 요청이 성공하고 음성이 재생됨
10. 과금 안내가 실제 계약과 일치함: 글로 보기만 서버 단가 차감, ▶ 듣기는 무료
11. 재생 중 카테고리 제목, 오전·오후 슬롯, 진행률, 경과·남은 시간이 표시됨
12. 일시정지·계속 듣기·처음부터·0.8/1.0/1.2배속 제어가 동작함
13. 무료 상태 API의 제목만 재생 위치에 맞춰 자막으로 표시되고 유료 본문은 노출되지 않음
14. 820px 이하에서 재생 중 뉴스룸이 상단에 고정되고, 600px 이하의 낮은 화면에서도
    제목 자막과 재생 제어가 이미지 안에 유지됨

### ★화면(묶음 B)이 반드시 지켜야 할 것

1. **`status:'unavailable'` 인 칸은 숫자를 만들지 말고** "잠시 후 다시"로 표시한다.
   실패해도 `price`/`change` 는 `null` 이지 `0` 이 아니다 — `?? 0` 같은 폴백을 넣지 말 것.
2. **`fx.hasRate === false` 면 `1,380원` 류의 값을 절대 찍지 말 것.**
   이때 `rateSource === 'toss-etf-direction-only'` 이고 `rate` 는 `null` 이다.
   `fx.proxy.price`(16,160원대)는 **ETF 가격이지 환율이 아니다.** 방향(`direction`,
   `changePct`)만 유효하므로 "달러 ↓ 0.34%" 식으로만 쓴다.
   ```json
   { "status":"ok", "rateSource":"toss-etf-direction-only", "hasRate":false,
     "rate":null, "change":null, "changePct":-0.34, "direction":"down",
     "proxy":{"symbol":"138230","name":"KODEX 미국달러선물","price":16160,
              "note":"ETF 가격이며 원/달러 환율이 아니다. 등락 방향만 유효하다."} }
   ```
3. 코스피·코스닥은 **네이버 실시간 지수가 1차**다(2026-08-27 변경).
   응답의 `valueKind` 로 표기를 가른다 — 여기서 갈리지 않으면 오해가 생긴다.

   | `valueKind` | 값 | 화면 표기 |
   |---|---|---|
   | `index` | 6,912.37 | 소수 둘째 자리까지. ★**'원'을 붙이지 않는다** |
   | `etf`   | 109,135  | `109,135원` + `proxy.name`(대용 ETF)을 함께 노출 |

   ★**대용 ETF 는 근사가 아니다.** 자릿수도 등락률도 다르다
   (지수 +1.53% vs KODEX 200 +1.32%, 실측 2026-08-27). 지수를 못 받은 칸만 폴백한다.
   ★`proxy` 는 **ETF 폴백일 때만** 내려간다(옵셔널).
4. `date.timeOfDay`(`morning|afternoon|evening`)와 `date.hour` 는 **서버 KST** 값이다.
   인사말 분기는 브라우저 시계가 아니라 이 값을 쓴다. 이미지 조명 필터는 사용하지 않는다.
5. **뉴스는 이 라우트에 없다.** 카테고리는 `/api/news/categories`(무료),
   본문은 사용자가 누를 때만 `/api/news/today`(유료, 서버 설정 단가).
