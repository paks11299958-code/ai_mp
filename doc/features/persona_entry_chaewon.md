## 1. 왜 만들었나

윤채원은 **주식 전문가**인데 페르소나에 들어가면 채팅창부터 떠서
**무엇을 볼 수 있는지**가 안 보였다. 사장 지시는 구체적이었다 —
"주식 전광판에 빨간 화살표가 올라가는 효과".

시안은 허드 AI(메이커-체커)로 시작했다가 사장 지시 **"너가 다듬어"** 로
직접 v2를 만들고 여러 차례 피드백을 반영한 뒤 **"반영해"** 로 이관했다.

## 2. ★새로 만든 게 아니라 연결한 것이다

쓰는 API 넷은 **전부 이미 있던 것**이다. 새 API·새 테이블·새 크론이 없다.

| API | 무엇 | 비고 |
|---|---|---|
| `/api/desk/summary` | 코스피·코스닥·환율 | **서아 뉴스데스크가 쓰던 것** |
| `/api/stock-picks` | AI 관심 종목 | 09-07 신설(같은 날) |
| `/api/stock-picks/paper` | 가상매매 성적 | 자동매매 페이퍼 계좌 |
| `/api/news/status` | 뉴스 제목 | 무료 제목만(본문은 유료 50P) |

넷 다 **공개 읽기**라 **진입만으로 0P**. 진입 랜딩 공통 원칙이다.

★한 API가 죽어도 나머지는 그린다(각 `fetch` 가 따로 `catch`, 실패한 것만 하단에 표시).

## 3. 구성

전광판 → 뉴스 → 가상매매 → 관심 종목 → 메뉴 → 초대 → 면책

- **전광판 반반** — 좌: 코스피·코스닥·원/달러 / 우: 코스피 추세 그래프
  (`stroke-dasharray` 로 선이 그려지는 효과 = 사장이 요청한 "올라가는 효과")
- **티커** — 지수·환율이 흐른다. ★두 벌을 이어 붙여야 흐를 때 왼쪽이 안 잘린다.
- **증권 탑뉴스 3탭** — 경제·증시 / 해외 / AI·기술.
  ★주식과 직결된 것만 넣었다(스포츠·날씨까지 넣으면 화면의 정체성이 흐려진다).
  탭 전환에 **추가 호출이 없다**(마운트 때 한 번만 받는다).
- **가상매매 성적** · **AI 관심 종목** · 메뉴 2개(내 종목 분석 / 대화하기)

★상승=빨강, 하락=파랑 (한국 증시 관례).

## 4. ★★화면 순서 — 두 번 고쳤다

사장 **"위치도 중요한 거 같은데"**. 이 화면은 회원의 질문에 **순서대로** 답한다.

| 순서 | 회원의 질문 | 답하는 블록 |
|---|---|---|
| ① | 여기 살아있나? | 전광판 · 뉴스 |
| ② | **믿을 만한가?** | **가상매매 성적** |
| ③ | 뭘 보고 있는데? | 관심 종목 |
| ④ | 내 것도 봐주나? | **메뉴**(300pt) |

**틀렸던 것 1 — 메뉴가 ② 자리에 있었다.** 회원이 스크롤을 시작하자마자 300pt 결제를
만나는 순서였다. 윤채원이 뭘 하는 사람인지 보기도 전에.

**틀렸던 것 2 — 가상매매를 관심 종목 뒤로 보냈다가 되돌렸다.** "예측 다음에 결과"라는
서사는 그럴듯했지만, 관심 종목 카드가 표까지 달려 길어서 그 아래는 스크롤 끝이었다.
★**안 보이는 자리에 둔 신뢰의 근거는 없는 것과 같다.**

실측(390px): 전체 1594px 중 가상매매 526px · 메뉴 1246px.

## 5. 🔴표현 규칙 — 완화 금지 (투자자문 소지)

- **'추천/매수'가 아니라 '관심 종목'.** 점수는 관심 높음(80+)/관심(60+)/참고.
- ★★**API `summary` 원문에 `| 투자의견 | **매수 (80점)** |` 이 그대로 들어 있다.**
  `투자의견|봇 추세|매수|매도|추천` 행을 **걸러낸다**(`DROP` 정규식). 남기는 건
  목표주가·현재주가·상승여력·핵심 리스크뿐. **이 필터를 풀면 화면에 "매수"가 나온다.**
- 🔴**봇 보유 종목명 비공개**(사장 지시). 수익률·손익은 **지나간 성과**지만 보유 종목은
  **지금의 포지션**이라, 페이퍼 계좌라도 회원에겐 매수 신호로 읽힌다 — 실계좌를 가리는
  이유와 같다. "보유 2종목"까지만.
- 🔴**실계좌는 애초에 부르지 않는다**(서버도 안 내려준다). 페이퍼만.
- **손실이어도 그대로 낸다.** 잘 될 때만 보여주면 그게 광고가 되고, 그때부터 투자 권유
  소지가 생긴다. 항상 보여주는 쪽이 법적으로도 안전하다.
- **지수엔 '원' 금지** — `valueKind==='etf'` 일 때만 원 + 대용 ETF 이름 병기
  (2026-08-28 서아 사고의 재발 방지). ★단 **금액**(목표주가·현재주가)에는 붙인다 —
  지수가 아니다.
- **면책 고정 노출**.
