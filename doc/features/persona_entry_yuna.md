## 1. 왜 만들었나

유나는 담당 기능이 **둘뿐**(`tarot` 타로점 보기, `tarot-daily` 오늘의 카드)인데 들어가면
채팅창부터 떠서 **"별을 읽는 타로술사"라는 정체가 안 보였다.**

## 2. 리서치가 설계를 바꿨다

사장 지시가 "**리서치 개발 방식으로**" 만들라는 것이었고, 실제로 조사가 설계를 바꿨다.

| 조사 결과 | 설계에 반영된 것 |
|---|---|
| 3장 스프레드 표준은 **과거·현재·미래** | 히어로 카드 3장의 자리 라벨 |
| 핵심은 "따로 보지 말고 **이야기로 이어 읽기**" | 카드가 열릴 때 문장이 **이어 붙는** 연출 + 본문 3단계 설명 |
| 기존 `TarotCardModal` 이 **이미 같은 3장 구조**(+`mode:'daily'`) | 새로 만들지 않고 **있는 의식을 예고편으로** 보여주는 방향 |
| 모달 색 = 자주+황금+**양피지(#f7edd8)** | 랜딩이 같은 팔레트를 이어받음 |

※ 서양 점성술 UI 표준(deep aubergine + starlight + champagne-gold)과도 일치해서,
   기존 색을 그대로 쓰는 것이 정체성에도 맞았다.

## 3. 🔴★★유나만 구조가 다르다 — 타로는 보드형이 아니라 **채팅형**

이 화면에서 가장 중요한 제약이다.

카드를 다 뽑으면 `handleSendMessage()` 로 유나에게 메시지를 보내고 **답이 채팅창에 뜬다**
(App.tsx `tarotAutoSendRef`). 이것이 **메시지당 과금**(MenuLimit 등록 없음)의 이유다.

그런데 타로 모달은 App.tsx **chat return 안에서만** 렌더된다(2236줄).
그 앞 1724줄에 `if (screen === 'main')` 얼리리턴이 있어 **main 에는 모달이 아예 없다.**
그리고 랜딩은 main 에서 열린다.

| 방법 | 결과 |
|---|---|
| `onFeature('tarot')` | 🔴 모달이 없어 **아무 일도 안 일어난다** |
| main 에 모달만 추가 | 🔴 카드는 뽑히는데 **답이 안 보이고 포인트만 나간다** |
| **`onStart('tarot')`** | ✅ `goTo('chat')` 후 기존 핸들러 → 과금·결과가 **검증된 경로**로 |

→ 기능 2개 모두 **`onStart(key)`** 로 부른다. 랜딩이 실행을 흉내내지 않으므로
  **이중과금**(도결에서 실제로 터졌던 사고)도 원천 차단된다. 결과적으로 App.tsx 무수정.

★★**기능을 랜딩에 붙이기 전에 "그 기능의 결과가 어디에 그려지는가"부터 확인할 것.**
보드형(윤채린·아린)은 main·chat 양쪽에 렌더돼 전환이 불필요하지만,
채팅형은 **채팅 화면이 반드시 필요하다.**

## 4. 연출 (사장 지시)

> "별자리 타로술사니 **공전 속도·위치가 서로 다른 비스듬한 타원 태양계**가 돌고,
>  그 아래 **타로 카드가 날아와 3장이 하나씩 열리는** 것"

```
별밭(70개, 각자 다른 주기로 반짝)
 └ 태양계 — rotateX(64deg) rotateZ(-12deg) 로 눕히고 기울인 타원 궤도 5개
    · 행성마다 반지름(34~118) · 주기(6~30s) · 크기 · 색 · 시작위치가 전부 다름
 └ 카드 3장 — 위(태양계 쪽)에서 날아와 자리를 잡고 차례로 뒤집힘
    · 뒤집힌 뒤 **옆으로 더 돌아** 비스듬히 선다: 180 → 228 → 212
      (정면에서 멈추면 "돌았다"가 안 보인다. 내밀어 보여주는 몸짓)
 └ 리딩 — 카드가 도는 순간 한 마디씩 이어 붙는다
```

- ※ **초안의 흰 연기는 사장 지시로 제거**했다.
- 실행 상태(정지 화면)만 필요한 사용자를 위해 `prefers-reduced-motion:reduce` 대응.

### 만들며 잡은 함정 3가지

- 🐛**궤도를 눕히면 행성도 같이 찌그러진다** → 행성만 `rotateZ(12deg) rotateX(-64deg)` 로 되세움.
- 🐛**카드가 `rotateY(180deg)` 로 뒤집히면 자식 라벨까지 거울상**이 된다
  (과거·현재·미래가 반전돼 읽혔다) → 라벨을 한 번 더 뒤집어 되돌림.
- 🐛리딩을 카드 위에 한 줄씩 넣으니 **카드 폭(78px)을 넘겨 옆 카드와 겹쳐 잘렸다**
  → **아래 한 문장**으로 모음. 3장은 어차피 이어 읽는 것이라 의미도 더 맞다.
