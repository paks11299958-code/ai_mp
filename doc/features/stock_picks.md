## 1. 왜 윤채원인가

사장이 처음 제안한 건 윤채린이었으나 **윤채원으로 확정**했다.

- 윤채린은 **얼굴 4종**(헤어·의상·시간여행·닮은꼴) 담당이고 랜딩도 'AI 스튜디오'다 —
  주식이 섞이면 정체성이 깨진다([[feedback_design_identity_first]]).
- 윤채원은 이 발굴을 **직접 만드는 당사자**이고, 기능이 '주식 분석' 하나뿐이라 메뉴도 허전했다.

## 2. ★★법적 경계 (문구를 바꿀 때 이 선을 넘지 말 것)

회원에게 종목을 보여주는 것은 **투자자문 소지**가 있다. 그래서:

| 규칙 | 적용 |
|---|---|
| 이름 | "추천 종목" ✗ → **"AI 관심 종목"** ✓ |
| 점수 표기 | "매수/추천" ✗ → **관심 높음 / 관심 / 참고** ✓ |
| 면책 | 화면 하단에 **스크롤 밖 고정** — "투자 권유가 아니며 판단·책임은 본인에게" |
| 🔴 봇 보유 종목 | **내려보내지 않는다** — 사장 계좌의 실제 포지션이다 |
| 종목코드·내부 판정치 | 내려보내지 않는다(`name`/`score`/`summary` 만) |
