# 북크크(BOOKK) 전자도서 내지 양식 규격

> 출처: 사용자 제공 실제 출판 샘플 `[전자도서]AI 초보자를 위한 쉬운 입문서 어렵지 않아요_신지윤(501170, 내지).pdf` (53p, 2026-06-10 분석).
> 이 규격을 puppeteer PDF 생성(탭5 초안 / 탭6 완성본)의 CSS 기준선으로 사용. 전자책 프로세스 본문: [[ebook_pipeline]].

## 문서 종류
- **전자도서 "내지"** (eBook interior). 표지는 1페이지에 포함된 형태(별도 표지 파일 아님).
- 세로형 페이지, 좌우 균등 여백, 하단 중앙 푸터.

## 페이지 구성 순서
1. **표지(p.표지)**: 책 제목(명조 대형) + 부제 + 표지 일러스트(중앙 큰 박스) + 하단 박스에 제목 재기재 + 저자명(우측) + **BOOKK 로고**(우측 하단).
2. **판권면(본문 p.1)**: 상단에 제목(키워드 볼드)+부제 / 가로 굵은 구분선 / 메타 표(라벨 파랑·값 검정): 발행·저자·펴낸이·출판사등록·주소·전화·이메일·**ISBN** / 가로 구분선 / `© 2026 저자. All rights reserved.` + `이 책의 무단 전재와 복제를 금합니다.`(중앙) / `북크크(bookk.co.kr) 출판 플랫폼` + 안내문(중앙).
   - ※ 발행일·ISBN은 출판 시 북크크가 부여 → 생성 시 빈칸 또는 placeholder.
3. **목차(p.2~)**: `목 차` 대형(파랑) + `Contents`(이탤릭 회색) / 가로 굵은 구분선 / 장별 행: 좌측 `제 N 장`(장 컬러) + 우측 제목(볼드, 키워드 강조)+부제(회색). **각 행은 장 컬러 테두리 박스**. 목차가 길면 다음 페이지로 이어짐.
4. **본문(p.4~)**: 장마다 아래 "장 본문 패턴" 반복.

## 공통 고정 요소
- **하단 푸터(모든 본문 페이지)**: 중앙 정렬 `책제목 | N` — 페이지번호 N은 **파란 볼드**, 나머지 회색. 판권면을 p.1로 시작.
- 본문 정렬: **양쪽 정렬(justify)**, 줄간격 넉넉(약 1.9~2.0).
- 한글 본문 폰트: 고딕 계열(맑은고딕 류). 제목 일부는 명조(표지/목차 타이틀).

## 장(챕터) 본문 패턴 (위→아래)
```
제 N 장                         ← 작은 라벨, 장 컬러
《큰제목》                       ← 대형, 키워드(AI 등) 볼드, 장 컬러
▎부제                           ← 좌측 세로바(장 컬러) + 회색 텍스트
──────────────                  ← 장 컬러 가로 구분선(굵게)

▌소제목▐                        ← 장 컬러 꽉찬 배경 박스 + 흰 글씨
본문 단락 …                     ← justify, 단락 간 간격

[강조 박스]                      ← 연한 장 컬러 배경 + 좌측 두꺼운 컬러 바 + 아이콘 제목
                                   종류: 💡팁 / 🔍개념 / ⚠️주의 / 📚학습 / 🎨창작 /
                                        ⚖️윤리 / 💼역량 / 🛠도구 / 🌅루틴 / 🗺로드맵 / ✏️비교
(소제목/본문/강조박스 반복)

✦ 이 장의 핵심: 부제             ← 연한 장 컬러 배경 + 장 컬러 테두리 박스 (장 끝맺음)
```
- 새 장은 **새 페이지에서 시작**.

## 장별 컬러 순환 (양식의 핵심)
장 번호 % 5 로 색 순환. (큰제목·구분선·소제목 배경·강조박스·핵심박스 테두리에 동일 적용)

| 순번(=장%5) | 색 | 예시 장 | HEX(샘플 근사) |
|---|---|---|---|
| 1 | 파랑 | 1,7,13 / 마치며 | `#2F6FB5` (소제목배경) / 푸터번호 `#2F6FB5` |
| 2 | 빨강 | 2,8,14 | `#C0392B` |
| 3 | 초록(딥그린) | 3,6,9,12,15 | `#1F7A4D` |
| 4 | 주황 | 4,10 | `#E2591F` |
| 0 | 퍼플 | 5,11 | `#6B3FA0` |

- 강조박스 배경 = 해당 컬러의 아주 연한 톤(틴트), 좌측 바 = 진한 컬러.
- 핵심박스 = 연한 배경 + 컬러 테두리 1px.
- ※ 샘플은 6·12장이 초록 계열로 보임 → 실제는 "딥그린"이 3·6·9·12·15에 반복. 단순화하면 5색 순환(파/빨/초/주/퍼)로 충분.

## 폰트 크기 3단계 (사용자 설정 대상 — 탭5)
사용자가 ①큰제목 ②중간제목(소제목) ③본문 크기를 지정. 샘플 근사 기본값:
- 큰제목(장 타이틀): ~30pt
- 소제목(섹션): ~18pt (흰글씨 컬러박스)
- 본문: ~12pt, line-height ~2.0
- 푸터: ~10pt

## 표지 구성 (탭6 표지 생성)
- 상단: 제목(명조)+부제+저자명(작은 글씨)
- 중앙: 표지 일러스트(책 사이즈에 꽉 차게 — 정사각 큰 박스)
- 하단: 회색 테두리 박스 안에 제목 재기재 + 저자명(우측 하단) + **BOOKK 로고**(우측)

## 구현 메모
- puppeteer로 HTML+CSS → PDF. 위 패턴을 컴포넌트화(장 헤더 / 소제목 / 강조박스 / 핵심박스 / 푸터).
- 장 컬러는 `chapterIndex % 5`로 팔레트에서 선택해 CSS 변수 주입.
- 강조박스 종류(팁/개념/주의 등)는 본문 마크다운에 마커를 두거나, AI가 본문 생성 시 `:::tip` 류 펜스로 표시 → 파서가 박스로 변환.
- ISBN/발행일은 출판 후 부여 → 생성 PDF엔 비움.
- BOOKK 로고는 저작권 확인 후 사용(샘플엔 들어있으나, 우리가 자동 삽입 시 북크크 정책 확인 필요).
