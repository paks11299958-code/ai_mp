# AI 스튜디오 — GCP GPU 온디맨드 구축 기획서

> 작성 2026-08-05 · 상태: **기획안(미착수)** · 결정 필요 사항은 §7
> 사장 지시: "AI 스튜디오를 구축하려는데 GCP 서버 임대할 거고, **사용할 때만 켰다 껐다** 할 거다."

---

## 1. 무엇을 만드는가

**이미지 생성을 직접 돌리는 GPU 서버**를 두되, 쓸 때만 켜서 비용을 최소화한다.

지금은 이미지 생성을 전부 외부 API(gemini-3.1-flash-image, gpt-image-2)로 처리한다.
자체 GPU를 두면:

- **원가 절감** — 장당 과금이 사라지고 시간당 과금으로 바뀐다(대량 생성일수록 유리)
- **모델 자유도** — SDXL·Flux·LoRA 등 원하는 모델을 직접 올려 쓴다.
  API가 막는 화풍·구도 제약에서 자유롭다
- **실험 가능** — 프롬프트를 수십 장씩 돌려보는 실험이 부담 없어진다

★단, **외부 API를 대체하는 게 아니라 병행**한다. 한글 텍스트 렌더링(gpt-image-2)처럼
API가 확실히 나은 영역이 있고, 서버가 꺼져 있을 때도 서비스는 돌아야 한다.

## 2. 사양 — 무엇을 얼마에 빌리나

### 2-1. 결론: `g2-standard-4` (NVIDIA L4 24GB)

| 항목 | 사양 |
|---|---|
| 머신 | g2-standard-4 — vCPU 4, RAM 16GB |
| GPU | **NVIDIA L4 24GB VRAM** |
| 리전 | asia-northeast3 (서울) — 기존 서버1·2와 같은 리전 |

**왜 L4인가**: SDXL은 8GB, Flux 양자화판은 8~12GB, Flux 풀버전은 16~24GB를 쓴다.
L4의 24GB면 **Flux 풀버전까지 여유 있게** 돌아간다. 상위 A100(40GB)은 시간당
$3.67로 5배 비싼데, 이미지 생성엔 과잉이다.

**왜 T4가 아닌가**: T4는 15GB에 Tensor Core 세대가 낮아 SDXL에서 2~3배 느리다.
켜져 있는 시간만큼 돈이 나가는 온디맨드에서는 **느린 GPU가 오히려 비싸다.**

### 2-2. 가격 (2026-08 기준, 서울 리전)

| 구분 | 시간당 | 비고 |
|---|---|---|
| 온디맨드 | **$0.9077** (약 1,260원) | 안정적, 중단 없음 |
| **Spot VM** | **$0.2709** (약 375원) | **70% 할인**, 30초 예고 후 중단 가능 |

★**서울 Spot이 미국보다 싸다**($0.27 vs us-central1 $0.40). 리전을 옮길 이유가 없고,
기존 서버와 같은 리전이라 내부 통신도 유리하다.

### 2-3. ★꺼도 나가는 돈 — 디스크

**인스턴스를 꺼도 디스크 요금은 계속 나간다.** 온디맨드 설계의 핵심이다.

| 디스크 | 월 단가 | 200GB 기준 월 |
|---|---|---|
| Balanced PD | $0.10/GB | $20 (약 2.8만원) |
| SSD PD | $0.17/GB | $34 (약 4.7만원) |

모델 파일이 크다(SDXL 7GB, Flux 24GB, LoRA·VAE 등). **200GB면 충분**하고,
Balanced로 시작해 부족하면 늘린다(줄이는 건 안 되므로 작게 시작).

## 3. 비용 시뮬레이션 — 주 5~10시간 사용 기준

사장 예상 사용량(주 5~10시간 = **월 20~40시간**)으로 계산한다.

| 구성 | 월 20시간 | 월 40시간 | 비고 |
|---|---|---|---|
| **Spot + 200GB Balanced** | **약 3.8만원** | **약 4.9만원** | ⭐추천 |
| 온디맨드 + 200GB Balanced | 약 6.3만원 | 약 9.8만원 | 안정 우선 |
| 온디맨드 24시간 상시 | **약 92만원** | — | 참고: 안 끄면 이렇게 된다 |

계산: Spot $0.2709 × 시간 × 1,390원 + 디스크 $20 × 1,390원

**핵심**: 상시 가동 대비 **월 92만원 → 4만원대**로 떨어진다. 온디맨드의 실익이 크다.

★단 디스크 2.8만원은 **한 시간도 안 써도 나간다.** 월 사용이 10시간 미만으로
떨어지면 디스크가 비용의 대부분이 되므로, 그때는 **모델을 GCS에 넣고 디스크를
줄이는** 구조로 바꾸는 게 낫다(§6-3).

## 4. Spot을 쓸 것인가 — 판단

Spot은 70% 싸지만 **30초 예고 후 강제 종료**될 수 있다.

**이미지 생성 용도에는 Spot이 맞다:**
- 작업 단위가 짧다(장당 2~6초). 중단돼도 잃는 건 진행 중 1장뿐
- 사람이 앉아서 쓰는 대화형 작업이라, 끊기면 다시 켜면 된다
- 무인 배치가 아니므로 "새벽에 죽어서 아무도 몰랐다"가 안 생긴다

**Spot이 위험한 경우**(이번엔 해당 없음):
- 장시간 학습(수 시간짜리 파인튜닝) — 중간에 죽으면 처음부터
- 서비스 실시간 응답 — 회원이 기다리는 요청을 GPU가 처리하는 구조

→ **1단계는 Spot으로 시작.** 나중에 회원 서비스에 직접 물릴 때 온디맨드로 승격한다.

## 5. 어떻게 켜고 끄나 — 운영 설계

### 5-1. 켜기: 어드민 버튼 한 번

```
어드민 [AI 스튜디오] 탭
  [🟢 서버 켜기]  ← 누르면 gcloud compute instances start
       ↓ 약 40~60초 (부팅 + ComfyUI 기동)
  [열기] 버튼 활성화 → ComfyUI 화면으로 이동
```

★**터미널을 안 열어도 되게** 만드는 게 핵심이다. 매번 SSH로 켜야 하면 결국 안 쓰게 되고,
켜둔 채 잊어버려 요금이 샌다.

### 5-2. 끄기: 자동이 정본, 수동은 보조

**★자동 종료가 이 기획의 성패를 가른다.** 끄는 걸 사람에게 맡기면 반드시 잊는다.

3중으로 건다:

1. **유휴 감지 자동 종료** (주 방어)
   서버 안에서 30분마다 확인 → ComfyUI에 최근 30분간 요청이 없으면 스스로 shutdown
2. **최대 가동시간 상한** (보조)
   켠 지 4시간이 지나면 무조건 종료. 유휴 감지가 고장나도 하루 최대 4시간으로 막힌다
3. **일일 점검 알림** (감시)
   매일 3시간 상태보고(monitor.js)에 **AI 스튜디오 상태**를 추가 —
   켜져 있으면 "🟡 AI 스튜디오 가동 중 (2시간 30분째)"로 보고

★교훈 적용: 07-31 토스봇이 손실한도로 멈췄는데 알림이 0건이라 다음날까지 몰랐다.
**"꺼져 있는 게 정상"인 자원은 켜져 있을 때 반드시 눈에 띄어야 한다.**

### 5-3. 요금 상한 알림

GCP 예산 알림을 **월 10만원**에 걸어 초과 시 텔레그램으로 받는다.
자동 종료가 전부 실패해도 이게 마지막 안전망이다.

## 6. 구축 단계

### 6-1. 1단계 — 최소 구성 (반나절)

1. `g2-standard-4` Spot 인스턴스 생성 (서울, 200GB Balanced, GPU 드라이버 이미지)
2. ComfyUI + SDXL/Flux 모델 설치
3. 외부 접근은 **IP 화이트리스트 + 기본 인증**만 (공개 노출 금지)
4. 수동으로 켜고 꺼보며 부팅 시간·생성 속도 실측

**이 단계에서 확인할 것**: 부팅 40~60초가 실제로 맞는지, L4에서 장당 몇 초인지.
예상보다 느리면 사양을 재검토한다.

### 6-2. 2단계 — 자동화 (반나절)

1. 유휴 감지 스크립트 + 최대 4시간 상한
2. 어드민 [AI 스튜디오] 탭 — 켜기/끄기/상태
3. monitor.js에 가동 상태 추가
4. GCP 예산 알림 설정

### 6-3. 3단계 — 서비스 연동 (검토 후 결정)

쇼츠·프로필사진 등 **기존 기능이 이 GPU를 쓰게** 할지는 나중에 판단한다.

★**신중해야 하는 이유**: 회원 요청을 GPU에 물리면 "서버가 꺼져 있으면 기능이 죽는다".
켜는 데 1분이 걸리는데 회원은 기다리지 않는다. 붙인다면
**API 우선 → GPU는 관리자 배치 작업만** 같은 구조여야 한다.

## 7. ★결정이 필요한 사항

1. **Spot vs 온디맨드** — 기획안은 Spot 권장(중단 감수, 70% 절감)
2. **디스크 200GB로 시작** — 모델을 많이 올릴 계획이면 500GB(월 7만원)
3. **최대 가동시간 4시간** — 더 길게/짧게 조정 가능
4. **3단계 서비스 연동 여부** — 1·2단계만 하고 관리자 전용으로 둘지
