## 문제 1: 쿠팡 Open API HMAC 인증 오류

### 증상
API 호출 시 `UNAUTHORIZED` 또는 `SIGNATURE_MISMATCH` 오류 발생

### 원인
- 연도 포맷: `yyyyMMdd` (4자리) → 쿠팡은 `yyMMdd` (2자리) 사용
- 구분자: `\n`으로 구분 → 쿠팡은 구분자 없이 이어붙임

### 조치
```javascript
// 올바른 서명 포맷
const dt  = `${yy}${MM}${dd}T${HH}${mm}${ss}Z`;  // 2자리 연도
const msg = dt + method + urlPath + query;           // \n 없이 이어붙임
const sig = crypto.createHmac('sha256', SECRET_KEY).update(msg).digest('hex');
```

## 문제 5: 쿠팡 이미지 승인반려 — CDN 접근 차단

### 증상
상품 등록 후 "승인반려" — 사유: 이미지를 다운로드할 수 없음

### 원인
도매꾹 CDN(`cdn1.domeggook.com`)이 외부 서버(쿠팡)의 이미지 다운로드를 핫링크 차단으로 막음

### 시도한 방법 (실패)
- 서버에서 직접 `fetch(imageUrl)` → 403/404
- Coupang CDN 업로드 API(`/v2/.../vendor-items/image`) → `PRECONDITION_FAILED` (엔드포인트 불명)

### 최종 해결
Playwright `page.request.get()`으로 브라우저 세션을 통해 이미지 다운로드 → `vendorPath`로 전달하면 쿠팡 서버가 정상 다운로드
```javascript
const downloadImage = async (url) => {
    const r = await page.request.get(url, { headers: { 'Referer': 'https://domeggook.com/' } });
    if (!r.ok() || (await r.body()).length < 3000) return null;
    return { buffer: await r.body(), type: r.headers()['content-type'] };
};
```

### 원인
