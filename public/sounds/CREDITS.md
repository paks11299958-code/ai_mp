## 가공 내역

원본은 UI 효과음으로 쓰기엔 길어(2.4~56초) 실제 애니메이션 길이에 맞게 잘랐다.

```sh
# 셔플: 앞 1.6초 + 페이드아웃(애니메이션 ~1.4초에 맞춤)
ffmpeg -i src.mp3 -t 1.6 -af "afade=t=out:st=1.3:d=0.3,loudnorm=I=-20:TP=-2" \
       -ac 1 -ar 44100 -b:a 96k tarot-shuffle.mp3

# 뽑기: 단일 카드 구간 0.45초
ffmpeg -ss 1.0 -i src.mp3 -t 0.45 -af "afade=t=out:st=0.3:d=0.15,loudnorm=I=-20:TP=-2" \
       -ac 1 -ar 44100 -b:a 96k tarot-flip.mp3

# 완성 차임: 앞 1.2초
ffmpeg -i src.mp3 -t 1.2 -af "afade=t=out:st=0.9:d=0.3,loudnorm=I=-20:TP=-2" \
       -ac 1 -ar 44100 -b:a 96k tarot-reveal.mp3
```

- **모노 44.1kHz 96kbps**로 통일 — UI 효과음은 스테레오가 불필요하고 용량만 늘린다(합계 41KB).
- **-20 LUFS로 정규화** — 후보마다 음량이 제각각이라(최대 0.0dB로 클리핑 위험인 것도 있었다)
  기준을 맞춰야 재생 볼륨을 코드에서 한 값으로 통제할 수 있다.

## 새 효과음을 추가할 때

- 라이선스는 **CC0 또는 CC BY만**(사장 규칙: NC·ND 금지). CC BY면 이 표에 저작자 표기 필수.
- 길이는 실제 애니메이션 구간에 맞춰 자르고 위와 같은 옵션으로 정규화한다.
- 재생 로직은 `frontend/utils/sound.ts` 참고 — 볼륨·음소거 설정이 그곳에 모여 있다.
