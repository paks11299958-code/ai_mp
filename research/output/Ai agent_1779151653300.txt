# 클로드 코드로 AI 에이전트 만들기: 완전 가이드

---

## 클로드 코드란 무엇인가

클로드 코드(Claude Code)는 Anthropic이 만든 AI 기반 코딩 어시스턴트다. 일반적인 챗봇과 근본적으로 다른 점이 있다. ChatGPT에게 "이 코드 고쳐줘"라고 물으면 텍스트로 답변을 돌려주지만, 클로드 코드는 **직접 파일을 열고, 수정하고, 저장하고, 실행**한다.

비유하자면 이렇다. 일반 챗봇이 "요리 레시피를 알려주는 요리사"라면, 클로드 코드는 "직접 주방에 들어가서 요리를 완성해 주는 요리사"다.

Anthropic의 공식 문서에 따르면 클로드 코드가 할 수 있는 일은 다음과 같다:

- 기능 구축 및 버그 수정
- 커밋 및 풀 리퀘스트 생성
- MCP(Model Context Protocol)로 외부 도구 연결
- 에이전트 팀 실행 및 커스텀 에이전트 구축
- 반복 작업 자동화 및 예약 실행

---

## AI 에이전트와 에이전틱 워크플로우

클로드 코드를 제대로 활용하려면 **AI 에이전트(Agent)** 개념을 이해해야 한다.

일반 챗봇은 질문 → 답변의 단순 구조다. 반면 AI 에이전트는 다음 과정을 거친다:

1. **목표 수신** - 사용자로부터 원하는 결과를 전달받는다
2. **계획 수립** - 목표 달성을 위한 단계를 스스로 설계한다
3. **도구 사용** - 파일 시스템, 터미널, 외부 API 등을 연동한다
4. **실행 및 조정** - 중간에 예상치 못한 문제가 생기면 경로를 스스로 수정한다

예를 들어 "영문 논문 PDF를 한국어로 번역해줘"라는 지시를 받으면, 에이전트는 PDF 파일을 열고 → 텍스트를 추출하고 → 번역하고 → 서식을 유지하며 → 최종 문서를 저장하는 일련의 과정을 자율적으로 수행한다.

이것이 **에이전틱 워크플로우**다. 정해진 순서를 반복하는 단순 자동화와 다르게, 상황에 따라 판단을 바꾼다.

## 환경 세팅: 클로드 코드 설치하기

### 터미널 설치 (기본)

가장 범용적인 설치 방법이다.

**macOS / Linux / WSL:**
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows PowerShell:**
```powershell
irm https://claude.ai/install.ps1 | iex
```

설치 후 프로젝트 폴더로 이동해 `claude`를 입력하면 바로 시작된다. 처음 실행 시 로그인 절차가 진행된다. Claude 구독 또는 Anthropic Console 계정이 필요하다.

업데이트와 진단은 다음 명령어로 처리한다:
```bash
claude update    # 수동 업데이트
claude doctor    # 설치 상태 진단
```

### VS Code 연동 (추천)

**VS Code가 게임기, Claude Code가 게임팩** 역할이라고 보면 이해하기 쉽다.

VS Code 환경에서 클로드 코드를 쓰면 AI가 작업하는 과정을 실시간으로 눈으로 확인할 수 있다. 잘못된 방향으로 흘러가면 즉시 멈출 수 있어 안전성이 높다.

**세팅 순서:**
1. [code.visualstudio.com](https://code.visualstudio.com)에서 VS Code 설치
2. VS Code 확장 프로그램에서 **Claude Code** 검색 (게시자 Anthropic 확인)
3. 클로드 유료 계정으로 로그인
4. Python과 Node.js 설치 (클로드 코드가 만든 코드를 실제로 실행하려면 필수)

**한글 설정:** 왼쪽 사이드바 확장 프로그램 → Korean 검색 → Korean Language Pack 설치

VS Code 외에 **CURSOR**, **Obsidian**과도 연동이 가능하다.

## 핵심 설정: 권한 모드와 슬래시 명령어

### 권한 모드 설정

클로드 코드가 얼마나 자율적으로 움직일지를 결정하는 핵심 옵션이다.

| 권한 모드 | 설명 |
|---|---|
| Always Ask | 모든 작업에 권한 요청 (기본값, 가장 안전) |
| Accept Edits | 파일 편집만 자동 승인 |
| Bypass Permissions | 모든 권한 자동 승인 (YOLO 모드) |

`Shift + Tab` 단축키로 세 모드를 순환 전환할 수 있다.

에이전트가 알아서 작업하길 원한다면 `/config` 입력 → General config → **Claude Code: Allow Dangerously Skip Permissions** 체크. 단, 신뢰할 수 있는 환경에서만 사용해야 한다.

### 주요 슬래시 명령어

| 명령어 | 기능 |
|---|---|
| `/init` | 프로젝트 스캔 후 CLAUDE.md 자동 생성 |
| `/agents` | 에이전트 목록 관리 및 새 에이전트 생성 |
| `/config` | 설정 마법사 열기 |
| `/compact` | 대화 요약하여 컨텍스트 절약 |
| `/context` | 현재 컨텍스트 사용량 시각화 |
| `/memory` | CLAUDE.md 메모리 파일 편집 |
| `/review` | 현재 변경사항 코드 리뷰 요청 |
| `/rewind` | 코드 상태를 이전으로 되돌리기 |
| `/cost` | 토큰 비용 표시 |

## CLAUDE.md: 에이전트의 두뇌

**CLAUDE.md**는 클로드 코드가 작업을 시작할 때 가장 먼저 읽는 파일이다. 사람으로 치면 신입사원에게 건네는 **업무 매뉴얼**이다.

이 파일에 다음 내용을 담으면 된다:
- 이 프로젝트가 무엇을 하는지
- 어떤 규칙으로 코드를 작성해야 하는지
- 자주 쓰는 명령어나 패턴
- 절대 건드리면 안 되는 파일이나 폴더

`/init` 명령어를 치면 클로드 코드가 프로젝트를 자동으로 스캔해서 CLAUDE.md 초안을 작성해준다. 이후 `/memory` 명령어로 언제든 수정할 수 있다.

## 나만의 AI 에이전트 만들기: 5단계

### 1단계 — 프로젝트 생성

업무 단위로 **독립된 폴더**를 만들고 VS Code에서 연다. 블로그 에이전트, 논문 번역 에이전트, 코드 리뷰 에이전트를 각각 다른 폴더로 분리해 관리한다.

### 2단계 — 에이전트 설계서 작성

가장 중요한 단계다. 에이전트에게 일을 맡기기 전에 **내 업무를 언어로 분해**해야 한다. 설계서에는 다음 세 가지가 들어가야 한다:

- **What** - 무엇을 해야 하는가 (구체적인 업무 절차)
- **Why** - 왜 이 일을 하는가 (의도와 목적)
- **How** - 어떻게 해야 하는가 (방법과 기준)

설계서의 구체성이 결과물의 퀄리티를 결정한다. "블로그 글 써줘"가 아니라 "SEO 최적화된 2000자 분량의 기술 블로그 초안을 작성하되, H2 소제목 4개와 실제 코드 예제를 포함하고, 마지막에 행동 유도 문구를 넣어줘"처럼 구체적이어야 한다.

### 3단계 — 에이전트 설계 검토

**Plan Mode**를 활용해 설계서를 검토하고 구현 계획을 구체화한다. 인터뷰 프롬프트를 통해 클로드와 대화하면서 빠진 부분을 채운다.

### 4단계 — 에이전트 세팅

클로드 코드에서 `/agents`를 입력하면 새 에이전트를 만들 수 있다.

**생성 과정:**
1. `/agents` 입력 후 엔터
2. **Create new agent** 선택
3. 설치 위치 선택
   - **Project**: 해당 프로젝트에만 반영
   - **Personal**: 전역적으로 모든 프로젝트에서 사용
4. 에이전트 설명 입력 (예: "코드를 분석하여 사람이 이해할 수 있도록 쉽게 자연어로 알려주는 분석 에이전트")
5. 도구(권한) 설정
6. 모델 선택 (기본값 Sonnet)
7. 최종 리뷰 후 완성

**도구 종류별 설명:**

| 도구 종류 | 설명 |
|---|---|
| Read-only tools | 파일 읽기, 정보 조회 (안전) |
| Edit tools | 파일 수정, 삭제, 코드 변경 |
| Execution tools | 코드 실행, 터미널 명령어 입력 |
| MCP tools | Google Drive, Slack, GitHub 등 외부 서비스 연동 |
| Other tools | 웹 검색, 특정 API 호출 등 |

### 5단계 — 실행과 개선

실행 후 피드백을 반영해 에이전트를 계속 성장시킨다. 처음에는 주니어 사원처럼 부족하더라도, 피드백을 쌓을수록 점점 정교해진다.

## 서브 에이전트: 병렬 AI 팀 운영

### 서브 에이전트란

서브 에이전트(SubAgent)는 **특정 작업 유형을 처리하는 특화된 AI 어시스턴트**다. 하나의 Claude Code 안에 역할이 다른 여러 에이전트를 만들어 팀처럼 운영하는 개념이다.

서브 에이전트가 필요한 이유는 명확하다. 에이전트 없이 하나의 AI만 쓰면 대화가 길어질수록 **컨텍스트가 오염**된다. 앞선 대화 내용이 뒤섞이면서 토큰 효율이 떨어지고 응답 품질도 낮아진다. 서브 에이전트는 자신만의 독립된 컨텍스트 윈도우에서 작동하기 때문에 이 문제를 해결한다.

### 클로드 코드의 내장 서브 에이전트

Claude Code에는 기본으로 내장된 서브 에이전트가 있다:

- **Explore** - 코드베이스 검색 및 분석 전용. 모델은 Haiku(빠르고 저렴)를 사용하며 읽기 전용 도구만 허용된다. 파일을 수정하지 않고 탐색만 할 때 자동으로 호출된다.
- **Plan** - 구현 계획 수립 전용
- **General-purpose** - 범용 작업 처리

### 서브 에이전트 호출 방법

만든 에이전트는 `@` 기호로 호출한다:

```
@code-explainer 이 함수가 무슨 역할을 하는지 설명해줘
```

**병렬 처리**도 가능하다. 여러 에이전트를 동시에 호출하면 각각 독립적으로 작업을 수행한다:

```
@.claude/agents/code-explainer.md: A부분 코드 분석해줘
@.claude/agents/create-flow-chart.md: B부분 플로우차트 그려줘
```

두 에이전트가 동시에 각자의 작업을 처리해 결과를 반환한다. 마치 두 명의 직원에게 동시에 다른 업무를 지시하는 것과 같다.
